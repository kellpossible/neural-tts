# Pocket-TTS provider — handover & testing plan

This provider was authored without a machine that can run pocket-tts (no
network/model access at author time), so the code is written against the
pocket-tts public API but a few assumptions need on-hardware confirmation.
Everything below is what an agent on a real Linux + KDE + speech-dispatcher box
should do to verify (and, where needed, fix) the integration.

## What changed

New provider `providers/pocket-tts/`:
- `pyproject.toml` — deps `pocket-tts`, `numpy`, `protobuf`; torch/torchaudio
  pinned to the CPU wheel index (pocket-tts is CPU-only).
- `src/neural_tts_provider_pocket_tts/`
  - `__main__.py` — socket adoption + framed-protobuf serve loop (copied verbatim
    from kokoro-onnx; only class/logger names changed).
  - `provider.py` — `PocketTtsProvider`: warmup / list_voices / synthesize_stream /
    shutdown. Streams `model.generate_audio_stream(state, text)` through a
    thread + `asyncio.Queue` bridge. Resolves preset vs cloned voices; caches
    cloned voice states as safetensors under
    `~/.cache/neural-tts-daemon/pocket-tts/clones/`.
  - `engine.py` — `build_model()` → `TTSModel.load_model(language=...)`,
    honoring `TTS_POCKET_CPU_THREADS` / `TTS_POCKET_LANGUAGE`. `NATIVE_SAMPLE_RATE
    = 24_000` (Mimi), reconciled against `model.sample_rate` on load.
  - `voices.py` — `PRESET_VOICES` table (mirrors pocket-tts'
    `_ORIGINS_OF_PREDEFINED_VOICES`, 26 names) + `scan_cloned_voices()` for the
    user-drop dir. Preset ids are reserved against clones.
  - `pb/__init__.py` — empty; `neural_tts_pb2.py` is generated by `mise run gen-proto`.

Shared-file edits (all additive):
- `providers/registry.toml` — added `[providers.pocket-tts]`.
- `mise.toml` — added a `grpc_tools.protoc` block for the pocket-tts `pb/` dir in `gen-proto`.
- `scripts/download_models.py` — added `_fetch_pocket_tts()` + dispatch arm
  (warms model weights + one preset via the provider venv).
- `README.md` — added the Pocket-TTS section and intro bullet (now "six providers").

## Assumptions to confirm on real hardware

These come straight from the pocket-tts source but were not executed. If any is
wrong, the fix is localized to the file named.

1. **Package name / version.** `pip install pocket-tts` is the import `pocket_tts`.
   If PyPI publishes a different name or needs `git+https://github.com/kyutai-labs/pocket-tts`,
   update `pyproject.toml` `dependencies`. Confirm the min version pin (`>=0.1`).
2. **`generate_audio_stream(state, text)` signature & yield type.** Code assumes a
   blocking generator yielding 1-D torch tensors. If it yields numpy already, the
   `chunk.detach().to("cpu")` guard in `provider._stream` already handles it
   (`hasattr(chunk, "detach")`). If the arg order differs, fix `provider._stream`.
3. **`get_state_for_audio_prompt`** accepts a bare preset name, a `.wav` path, and
   a `.safetensors` path (all confirmed from source). `export_model_state(state, dest)`
   is importable from `pocket_tts`. If export lives elsewhere, fix the import in
   `provider._get_voice_state`.
4. **`model.sample_rate`** is an int-able attribute. Mimi is 24 kHz; the provider
   self-corrects `self.sample_rate` on load if it differs, so a wrong constant is
   non-fatal (just a log warning).
5. **torchaudio** — pocket-tts may or may not depend on it. The `[tool.uv.sources]`
   entry for torchaudio is harmless if it isn't a dependency. If `uv sync` complains
   about the CPU index resolution, drop the torchaudio source line.
6. **Preset language/gender table** is cosmetic (KDE picker labels only). Non-English
   presets: giovanni=it, lola=es, juergen=de, rafael=pt, estelle=fr; rest English.
   Adjust `voices.PRESET_VOICES` if any label is wrong.
7. **Long-text chunking.** `MAX_TOKEN_PER_CHUNK` exists upstream, so
   `generate_audio_stream` is assumed to chunk internally. If long paragraphs get
   truncated, add sentence chunking (pysbd) in `synthesize_stream` — see how
   moss-tts-nano splits before the stream loop.

## Testing plan (run in order)

### 0. Prereqs
Daemon venv exists: `mise run sync-daemon`. Repo has the other prereqs from the
README (speech-dispatcher, KDE, paplay).

### 1. Codegen — generate the pb2 module
```bash
mise run gen-proto
ls providers/pocket-tts/src/neural_tts_provider_pocket_tts/pb/neural_tts_pb2.py   # must exist now
```
Expect: "Regenerated neural_tts_pb2.py in all provider packages." and the file present.

### 2. Install the provider (venv + model)
```bash
mise run install-provider pocket-tts          # CPU-only; no --extra needed
```
Expect: `uv sync` succeeds (CPU torch), then the download step prints
`pocket-tts model ready, sample_rate=<N>`. Note the sample rate — should be 24000.
If `uv sync` is slow/large, confirm CUDA torch was NOT pulled (`providers/pocket-tts/.venv`
should not contain multi-GB nvidia wheels).

### 3. Standalone smoke test (no daemon) — the fastest failure isolation
```bash
providers/pocket-tts/.venv/bin/python - <<'PY'
import numpy as np
from neural_tts_provider_pocket_tts.engine import build_model
from neural_tts_provider_pocket_tts.voices import preset_entries, PRESET_VOICES
m = build_model()
print("sample_rate:", int(m.sample_rate), "presets:", len(PRESET_VOICES))
state = m.get_state_for_audio_prompt("alba")
chunks = list(m.generate_audio_stream(state, "Hello from pocket tts, testing one two three."))
pcm = np.concatenate([np.asarray(c.detach().to("cpu"), dtype=np.float32).reshape(-1) for c in chunks])
print("chunks:", len(chunks), "samples:", pcm.size, "peak:", float(np.abs(pcm).max()))
assert pcm.size > 0 and np.isfinite(pcm).all() and np.abs(pcm).max() > 0
print("OK")
PY
```
Expect: non-empty finite PCM with a non-zero peak. This validates assumptions 1–4
in one shot. If it fails, the traceback points directly at the wrong assumption.

### 4. Voice enumeration through the daemon
```bash
# enable the provider in config
$EDITOR ~/.config/neural-tts-daemon/config.toml     # add "pocket-tts" to [provider] enabled
bin/neural-tts-ctl reload-voices
bin/neural-tts-ctl status
mise run voices        # or: spd-say -o neural-tts --list-synthesis-voices
```
Expect: the 26 presets appear (alba, giovanni, lola, …) attributed to pocket-tts.

### 5. Preset synthesis end-to-end
```bash
spd-say -o neural-tts -y alba "Pocket TTS preset voice works."
spd-say -o neural-tts -y giovanni "Ciao, questa e una voce italiana."   # non-English preset
```
Expect: natural audio out of the default sink. Check `journalctl --user -u neural-tts.service`
for the "resolving preset voice state" / "pocket-tts model ready" logs.

### 6. Voice cloning
```bash
mkdir -p ~/.local/share/neural-tts-daemon/voices/pocket-tts
cp /path/to/clean_10s_sample.wav ~/.local/share/neural-tts-daemon/voices/pocket-tts/myvoice.en.wav
bin/neural-tts-ctl reload-voices
spd-say -o neural-tts -y myvoice "This is my cloned voice."
ls ~/.cache/neural-tts-daemon/pocket-tts/clones/    # myvoice.<mtime>.safetensors should appear after first synth
```
Expect: `myvoice` enumerated; first synth is slower (encodes the clip), a
safetensors cache file is written, and a second run reuses it (log:
"loading cached voice state"). Re-copy a different wav to the same name → cache
invalidates by mtime and re-encodes.

### 7. Regression
```bash
mise run reload-voices     # spawns every enabled provider to enumerate
```
Confirm kokoro/others still enumerate and synthesize (the shared edits are additive;
`gen-proto` rewrote every provider's pb2 identically).

## If something breaks
- Provider won't start: `journalctl --user -u neural-tts.service -f` while running
  a spd-say — the provider logs to stderr with the `neural_tts_provider_pocket_tts`
  logger names.
- Wrong sample rate / chipmunk audio: check step 2/3 printed rate vs
  `NATIVE_SAMPLE_RATE` in `engine.py` (self-corrects, but confirm the daemon
  resampled from the reported header rate).
- Uninstall to reset: `mise run uninstall-provider pocket-tts` (add `--purge-models`
  to also clear the HF-cached weights is NOT wired — pocket-tts uses the HF cache;
  clear `~/.cache/huggingface` manually if needed).

## Rollback
All changes are additive. To fully remove: delete `providers/pocket-tts/`, revert
the `[providers.pocket-tts]` block in `providers/registry.toml`, the pocket-tts
block in `mise.toml` `gen-proto`, `_fetch_pocket_tts` + its dispatch arm in
`scripts/download_models.py`, and the README additions. No other provider is touched.
